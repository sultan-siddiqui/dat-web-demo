# Dar Al Tamleek: website concept (English / Arabic)

A 12-page, bilingual (EN / AR, full RTL) proposal for Dar Al Tamleek, the Saudi Shariah-compliant home-finance company. Plain HTML, CSS and JS output, generated by a small Node build so each page is written once with both languages side by side.

## Run

```bash
python -m http.server 5190
```

Open `http://localhost:5190/`. The root page sends visitors to `/en/` or `/ar/` (saved choice, then browser language). The language button on every page jumps to the same page in the other language.

## Edit and rebuild

Content lives in `src/pages/*.mjs`. Every string is written as `t('English', 'عربي')`.

```bash
node src/build.mjs
```

This regenerates every page, the root `index.html`, `.nojekyll` and the favicon. Don't edit the generated HTML by hand.

## Clean URLs (GitHub Pages)

Each page is written as a folder with its own `index.html`, so addresses carry no `.html`:

| URL | File |
| --- | --- |
| `/en/` | `en/index.html` |
| `/en/financing/` | `en/financing/index.html` |
| `/ar/business/#realtors` | `ar/business/index.html` |

GitHub Pages (and any static host, including the local server above) serves these without rewrites. To publish, push the repository and set Pages to deploy from the root of the main branch. `.nojekyll` makes GitHub serve the files as they are. All links are relative, so the site also works from a project sub-path such as `username.github.io/dar-al-tamleek-web/`.

## Design

- **Concept: "the doorway".** "Dar" means home, so the recurring motif is an arch-shaped door. Hero images sit in arches, the home page opens a door to full screen as you scroll, and page transitions rise as an arch-topped curtain. The star from the logo is drawn stroke by stroke in the transitions, the hero, the CTA and the form confirmations.
- **Colours** come from the logo: star red `#E4312B` (sampled `#E8312A`) and wordmark slate `#6B6B73`, on warm ivory `#FAF6F0` with ink `#17151A` for contrast sections. One light theme, as requested.
- **Fonts (Google Fonts).** English uses Fraunces for display and Manrope for text. Arabic uses Alexandria for display and IBM Plex Sans Arabic for text.
- **Motion:** GSAP 3.13 + ScrollTrigger, plus Lenis smooth scrolling (vendored in `assets/vendor/`). Headings reveal line by line, sections fade up, counters run, images drift with parallax, buttons pull toward the cursor, and the Murabaha diagram is sticky while its steps scroll past. Everything turns off under `prefers-reduced-motion`.
- **Responsive:** tested at 375 px and 1440 px in both languages with no horizontal scroll. Phones get a sticky Call / Calculate / Register bar and a full-screen menu.
- **Not copied from ASG.** ASG is dark, with a globe, a percentage loader, a custom cursor and a film. This concept is light and warm, built on the arch and the star, with explanation-first sections such as the Murabaha diagram, the persona selector and the calculator.

## Linked to the existing platform

Customer login (`digital.daraltamleek.com`), complaints, survey, terms, privacy, BOD elections, careers detail pages, news articles, fatwa and financial-statement PDFs all point to the live site. The business inquiry, contact and register-interest forms are front-end prototypes: they validate and show a success state but **send nothing**. Connect them to the existing endpoints at launch.

## Brand assets

The star mark is a vector rebuild traced from the website logo (`assets/img/brand/mark.svg`, generated by `src/lib.mjs`). The wordmark is typeset (Alexandria / Manrope). The live site only publishes a 149×87 px PNG (`dat-logo-original.png`), so **ask for the official vector logo** and swap it in `logo()` in `src/lib.mjs`.

## To confirm with Dar Al Tamleek

1. **Maximum finance.** The home page says "up to SAR 30M", but the program particulars and FAQ say SAR 5M (land SAR 2M). The concept shows both, in the places where the current site uses them.
2. **Families served.** The counters say 20,000+ families. The English About page says "85,000 family members" and the Arabic one says "70,000 families". The concept uses 20,000+ everywhere.
3. **Qualifying age.** The FAQ says 20–68 at application. The particulars say 20–75 (age at the end of the term). The calculator uses 20–68 for age and ends the finance by 75.
4. **Illustrative APR.** The calculator uses the 6.43% APR from the SAMA disclosure example and is labelled as indicative.
5. **SIBOR** in the footer is the value shown on 16/11/2026. It needs a live feed.
6. **Board roles** (independent / non-independent) come from the Arabic board page.
7. **Translations.** Arabic copy reuses the official Arabic wording where it exists. New Arabic copy (taglines, explainer, calculator) should get a native review before launch.
